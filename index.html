02 / A project I've worked on recently

Meet Withra.

Withra is a private messaging application I'm developing as part of Westforge Holdings' product portfolio. The work has challenged me to think about messaging experiences, app structure, integrations and user trust—not just how individual screens look.

My recent work involves mobile development with React Native and Expo, along with Supabase-backed application development. The process has reinforced the value of testing, debugging and iterating on complex features.

The problem

Creating a communication experience that feels straightforward while prioritizing user trust.

What I've learned

Application architecture, integrations, debugging, testing and making technical tradeoffs.

How I work

Start from a real need, test assumptions, identify problems and improve deliberately.

Current stage

Ongoing development. This page does not claim a public production release or a verified encryption implementation.
