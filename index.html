02 / Something I've been building

Meet Withra.

Withra is a private messaging application I've been developing as part of Westforge Holdings' product work. The challenge is bigger than creating screens: it's thinking through how people navigate a messaging experience, how services fit together, and how to improve a complex product.

The project has given me hands-on exposure to modern mobile development workflows and the realities of testing, troubleshooting, and shipping software. Recent work has involved the React Native and Expo ecosystem and Supabase-backed application development.

What I taught myself in the past six months: While working on Withra, I have continued learning practical mobile application development through hands-on experimentation with React Native, Expo, and Supabase. I learned by consulting technical documentation, using AI tools to explore approaches, testing code, investigating errors, and improving features through repeated iterations.

The problem

People want communication tools that feel straightforward and respectful of their privacy.

What I'm learning

Application structure, iterative testing, debugging, integration decisions, and the tradeoffs involved in building reliable software.

The mindset

Start with the user's need. Build carefully. Test assumptions. Improve what doesn't work.

Current stage

Ongoing product development. This showcase does not claim a public production release or specific security guarantees.

03 / Why artificial intelligence

I want to move from using AI tools to understanding how to build with AI.

AI has changed how I approach research, prototyping, and solving technical problems. But using a tool is only the beginning. I want to understand how to design, evaluate, and responsibly integrate AI into real applications.

I'm especially curious about useful AI assistance in software workflows—without sacrificing user trust, privacy, or clarity. The Just Ventures fellowship is an opportunity to learn through structured practice and collaboration.
